# Original game prompt

The same brief used for these Choplifter experiments, preserved verbatim:

> create a playable clone of the broderbund game choplifter from 1982 watch a full gameplay video like https://www.youtube.com/watch?v=2KDxRSeDKy8 and do research online on the game mechanics and build a web-based version of the game using a modern web game framework

Reference video: [Apple II Longplay - Choplifter](https://www.youtube.com/watch?v=2KDxRSeDKy8), by [hirudov](https://www.youtube.com/@Hirudov).

Original game: *Choplifter!*, created by Dan Gorlin and published by Brøderbund for the Apple ][ in 1982. The prompt is an experimental brief, not a grant of rights to the original game or video.
